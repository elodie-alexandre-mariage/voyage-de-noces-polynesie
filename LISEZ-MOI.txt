MISE À JOUR SITE POLYNÉSIE — V7

Cette V7 remplace la V6.

Nouveautés :
- clic sur le logo d'une île = sélection de sa vignette et synchronisation carte/frise/fiche ;
- clic sur un point ou une date de la frise = sélection de l'étape correspondante ;
- pour les jours de transfert, la date sélectionne l'étape de destination :
  13 Moorea / 16 Maupiti / 19 Taha’a / 22 Bora Bora / 25 Tahiti / 26 Retour ;
- photo de couverture remontée légèrement sur desktop (point focal vertical 58 % → 64 %) ;
- toutes les fonctionnalités de la V6 sont conservées.

À remplacer dans le dépôt :
- index.html
- css/accueil.css
- js/accueil.js
- data/voyage.js

Le fichier js/accueil.txt est la copie lisible du JavaScript.
Le fichier data/voyage.txt est la copie lisible des données.
TEXTES-CHAPITRES-VALIDES.txt conserve les textes validés.

Après copie : Ctrl + F5, puis Commit to main et Push origin si tout est bon.
